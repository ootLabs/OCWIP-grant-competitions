# Prototyp wizualny, kierunek C

Makieta wyglądu, nie działający system. Dziewięć ekranów ścieżki wnioskodawcy w kierunku C ("prowadzenie za rękę").

```bash
cd prototype
npm install
npm run dev
```

Potem `http://localhost:3100`. Port 3100, żeby nie zderzał się z frontem produktu na 3000.

Opis plików, zakres i to, czego tu świadomie nie ma: [`../docs/map/prototype.md`](../docs/map/prototype.md). Uzasadnienie, dlaczego prototyp stoi obok produktu, a nie w nim: [`../docs/architektura.md`](../docs/architektura.md).
