# Log projektu

Krótki, gęsty zapis tego, co się wydarzyło i dlaczego. Najnowsze na górze.

**Czytaj 3 do 5 górnych wpisów**, gdy bierzesz pracę, a nie cały plik. To jest log, nie podręcznik: trwała wiedza należy do [`architektura.md`](architektura.md) (decyzje), [`map/`](map/README.md) (gdzie co leży) albo [`konwencje.md`](konwencje.md) (jak piszemy). Jeśli fakt będzie ważny za trzy miesiące, ląduje tam, a tutaj zostaje wskaźnik.

## Format, trzymaj się ściśle

```
## RRRR-MM-DD - krótki tytuł
**Zrobione:** co teraz działa, jedna linia.
**Decyzje:** co wybrano i dlaczego, po jednej linii. Tylko nieoczywiste.
**Uwaga:** co ugryzie następnym razem. Pomiń linię, jeśli nic nie ugryzie.
```

**Limit: 20 wpisów.** Dodajesz dwudziesty pierwszy? Przenieś najstarszy do `docs/log-archiwum/<rok>.md` w tym samym commicie. Limit jest sensem tego pliku: nieograniczony dziennik to plik, którego nikt nie czyta, a każda sesja za niego płaci.

Każdy wpis maksymalnie 5 linii. Nie opowiadaj procesu, nie wypisuj zmienionych plików (git wie), nie powtarzaj tego, co już mówi mapa.

Enum jedzie po drucie nazwą, atrybutem na typie, nie opcją w `Program.cs`. Uzasadnienia w [`architektura.md`](architektura.md).
**Uwaga:** Sprawdzone mutacją: bez obrotu stampa i bez zerowego interwału kopia ciasteczka przeżywa wylogowanie, a bez `OnRedirectToLogin` API oddaje 302 zamiast 401. Dwie pułapki z review: `TryAddScoped<ISecurityStampValidator>` jest cichym brakiem operacji, bo Identity rejestruje tam własny, oraz `Auth__SecureCookie` w compose musi być **puste**, nie `false`, inaczej lokalny wyjątek na http jedzie na produkcję. **Zostaje otwarte:** limitu prób logowania nadal nie ma (T-12.5), ekranu logowania i paneli też nie (T-15.2, T-15.3), więc `redirectPath` wskazuje dziś na trasy, których jeszcze nie ma. **Do dokliknięcia:** karta 7MkNtmIH nie ma checklisty na Trello, a serwer MCP daje tylko odczyt, więc checklistę i przeniesienie karty na Zrobione trzeba zrobić w przeglądarce.
